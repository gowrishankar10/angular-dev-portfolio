## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/gowrishankar10/Portfolio.git

# Navigate to project directory
cd Portfolio

# Install dependencies
npm install

# Start development server
npm start
# or
ng serve

# Build for production
npm run build
# or
ng build --configuration=production
```

## 🎨 Design System

### **Color Palette**
- **Primary Green**: `#10b981` (Emerald 500)
- **Secondary Teal**: `#14b8a6` (Teal 500) 
- **Dark Accent**: `#047857` (Emerald 700)
- **Light Accent**: `#34d399` (Emerald 400)

### **Typography**
- **Headlines**: Inter (Professional, modern)
- **Body Text**: Inter (Readable, clean)
- **Code**: JetBrains Mono (Developer-focused)

### **Animation Principles**
- **Easing**: Cubic-bezier curves for natural motion
- **Performance**: Hardware-accelerated transformations
- **Accessibility**: Respects `prefers-reduced-motion`
- **Timing**: Staggered animations for visual hierarchy
